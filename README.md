# 社区新生儿上门访视 · 黄疸记录与复查闭环

面向社区护理场景的移动端单页应用：产妇出院后，**社区护士**在同一母婴档案内完成上门访视预约查看、婴儿测量（体重 / 小时龄胆红素）、产妇与家庭观察、现场拍照、综合风险判断、复查 / 转诊 / 母乳指导 / 电话随访的闭环管理；**家属端**查看通俗风险说明、护理建议、复查时间、补交出生证明 / 出院小结 / 喂养记录、申请改约与线上咨询。

技术栈：**React 18 + TypeScript + Vite + Pinia**（通过 `useSyncExternalStore` 桥接到 React），照片存 IndexedDB，业务数据以 localStorage 模拟社区服务端，支持**离线草稿 + FIFO 同步队列**。

> 本项目为前端 / 全栈型应用的纯前端实现，内置模拟服务端（`src/lib/server.ts`），无需后端即可一键运行；因此不提供 Swagger UI。

## 一、本地启动

### 方式 1：Node 直接运行（推荐开发用）

```bash
npm install        # Node 18+（开发环境使用 Node 22 验证）
npm run dev        # http://localhost:5173
```

其他命令：

```bash
npm test           # 运行单元 + 集成测试（Vitest，27 个用例）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览生产构建 http://localhost:4173
```

### 方式 2：Docker / Compose 一键启动

```bash
docker compose up -d --build
# 打开 http://localhost:8080
docker compose logs -f
docker compose down
```

镜像为多阶段构建（node:22-alpine 构建 → nginx:1.27-alpine 托管静态文件，SPA 路由回退已配置）。

## 三、页面与功能地图

### 护士端
- **工作台**：未访视家庭 / 异常黄疸 / 产妇风险 / 随访待闭环四个统计口径；按风险与逾期排序；支持「今日待访视、异常黄疸、产妇风险、随访未闭环、未入门/改约、本地草稿」筛选。
- **母婴档案**（同一档案内聚合）：
  - 出院与预约：出生日期、出生体重 / 孕周、分娩方式、母乳或配方喂养、出院黄疸风险与高危因素、产妇伤口、地址、家属联系人、预约时间；
  - **上门访视表单**：上门结果（正常入户 / 无人在家 / 不愿开门 / 临时改约）、体重、TcB 额/胸、TSB、设备故障标记、脐带（多选）、大小便次数与**大便颜色**、胎便转黄、喂养方式/频次/含接、吐奶、睡眠、产妇乳房/情绪/**EPDS 与第 10 题**/伤口、家庭照护能力、现场照片（黄疸比色卡/脐带/大便）、备注；
  - 表单底部是**实时综合判断预览**，提交后自动生成复查 / 转诊 / 母乳指导 / 心理转介 / 电话随访任务；
  - 访视时间线、复查转诊（可记录结果**闭环**）、资料、线上咨询、改约。
- **随访闭环中心**（底部导航）：待处理 / 已逾期 / 已闭环三栏。
- **同步中心**（底部导航）：切换设备联网 / 社区服务端故障、查看 FIFO 队列与本地草稿、手动重放、重置演示数据。

### 家属端
- 护理建议：宝宝目前情况（通俗四级表述）、**风险说明**（把出生天数和数值一起解释，而不是只报一个数字）、居家护理建议、red 级别的立即就医指引；
- 复查安排：下一次时间、全部复查/转诊/随访及闭环反馈、在线申请改约；
- 我的资料：拍照补交出生证明、出院小结、喂养记录（离线先存本机）；
- 问护士：线上咨询消息。

### 综合风险引擎（`src/lib/risk.ts`）
判断**不停留在单次黄疸值**，同时纳入：

1. **胆红素 × 出生小时龄**：Bhutani 百分位列线（P25/P50/P75/P95 锚点插值），同一个 15 mg/dL 在 48 小时是高危区、在 96 小时只是中高危区；距 P95 ≤1 mg/dL 判为临界并安排 12–24 小时复查；≥20 或 48 小时内超 P95 直接急诊；并计算较前次的上升速度（>0.2 mg/dL/h 转诊）；
2. **体重变化**：较出生体重下降 7%/10%/12% 三级，叠加"较上次是否止跌回升"；
3. **喂养**：24h 哺乳 <8 次、含接无效 → 母乳指导；
4. **大小便**：灰白陶土便立即急诊（胆道闭锁红旗征）、浅色便转儿科、72h 胎便未转黄、第 4 天后小便 <6 次；
5. **脐带 / 吐奶**：脐炎征象、喷射性呕吐转儿科；
6. **产妇**：EPDS ≥9 电话随访、≥13 心理转介、第 10 题阳性立即危机干预；乳腺炎 / 乳头问题 / 伤口异常；
7. **家庭照护能力**：信心不足 → 增加电话随访；
8. **上门异常**：拒绝开门 / 无人在家（高危家庭升级）、家长要求线上咨询；
9. 出生背景加权：早产、G6PD 缺乏、溶血、同胞光疗史等。

输出：综合分级（绿 / 黄 / 橙 / 红）、处置动作集合、建议复查时间、护理建议、家属端通俗解释。

### 离线现场工作流
1. 上门前在网络条（或同步中心）切到「现场离线」；
2. 填写访视：随时点 **💾 存本地草稿**——草稿只存本机（localStorage 镜像 + IndexedDB 照片），不改预约状态、不生成随访；
3. 现场完成后点提交：记录入 **FIFO 同步队列**，自动任务同时生成；
4. 回到社区打开「设备联网」，队列自动按顺序重放（服务端故障会保留队列，恢复后重试），成功后实体变为「已同步」。

## 四、建议的手工验证路径

1. `npm run dev` 后以护士 **王秀兰** 登录，确认工作台 4 个统计数字与风险排序；
2. 进入 **张一诺（A1001）→ 开始上门访视**，体重填 `3000`、TcB 胸部填 `16`（生后约 30h，超过该小时龄 P95），观察实时预览变为红/橙并出现急诊或转儿科动作；
3. 顶部网络条切「离线」，提交访视 → 出现「N 条待发」，档案列表出现「本地草稿/待同步」；
4. 进入同步中心查看队列 → 切回联网 → 队列自动清空、记录变「已同步」，随访闭环中心出现对应任务；
5. 打开 **刘念安（A1004）**，在复查任务上「记录结果并闭环」；
6. 退出后用访问码 **A1003** 进入家属端，查看风险说明与 12h 复查安排，提交一条咨询消息，再回护士端在该档案的「咨询」标签回复。

- `npm test`（Vitest + jsdom）：**27 个用例全部通过**，覆盖

> 医学说明：阈值参考新生儿高胆红素血症小时龄管理（Bhutani 列线图）与社区新生儿访视常规做了教学级简化，**不能用于真实临床决策**；实际使用须由妇幼保健机构审定规则并对接检验/ HIS 数据。
